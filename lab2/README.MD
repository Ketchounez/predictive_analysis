# Лабораторная работа № 2

Виртуальный датчик оценивает концентрацию продукта в печи каждую минуту по текущей и прошлой телеметрии. В `virtual_sensor_lab2.ipynb` собраны анализ данных, расчёт признаков, обучение трёх моделей и отчёт по результатам.

## Запуск

1. Положить `data_train.csv`, `target_train.csv`, `data_test_small.csv` и `target_test_small.csv` из материалов задания рядом с ноутбуком.
2. Создать окружение на Python 3.13, установить зависимости и открыть ноутбук из папки с файлами.

   ```bash
   python3.13 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python -m notebook virtual_sensor_lab2.ipynb
   ```

   В Windows для создания окружения используется `py -3.13 -m venv .venv`, для активации в PowerShell — `.\.venv\Scripts\Activate.ps1`.

3. Запустить все ячейки сверху вниз.

## Интерпретация результатов

При основном расчёте метку лабораторного результата сдвигаю на 12 минут назад. В ноутбуке показано, как меняется ошибка при сдвигах 0, 10, 12 и 15 минут. Для каждой пробы прогноз берётся на расчётное время отбора.

Случайный лес с короткой историей выбран по MAE на временной валидации. На 318 тестовых пробах его MAE составил 0,0627 в шкале CSV, WAPE — 29,91%, точность направления — 55,9%. В таблице есть результаты остальных моделей. MAE и RMSE показывают размер ошибки, MAPE и WAPE выражают её в процентах, MDA показывает, как часто модель угадывает подъём или спад между соседними пробами.

После выполнения `pred_minute` содержит прогнозы на все минуты теста, а `pred_at_lab` — те же прогнозы на метках проб. На графике за двое суток линия показывает минутный прогноз, точки — лабораторные измерения.
